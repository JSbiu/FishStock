# FishStock 产品定义

## 产品定位

FishStock 是面向开发者的轻量 VS Code 自选股工具。它只解决一个问题：编码过程中无需离开编辑器，就能安静地看一眼少量关注股票的价格和涨跌状态。

产品关键词是：低干扰、本地优先、透明、克制。

## 目标用户

- 日常在 VS Code 或兼容编辑器中工作，希望偶尔查看行情的开发者
- 只需要维护小型自选列表，不需要投资组合管理的人
- 重视隐私，不希望为了基础行情注册产品账户或上传自选数据的人

## 核心场景

1. 用户在 Activity Bar 打开 FishStock，以“分组 → 股票”两层结构快速扫视自选。
2. 用户在状态栏看到一只股票的简短行情，几秒后自动轮播到下一只。
3. 用户按名称、简称或代码搜索股票，确认匹配结果后直接加入目标分组；科创板和北交所不因板块类型被遗漏，其他自选变更也只保存在本机。
4. 用户发现行情刷新失败、市场休市或数据已经过期时，能够理解当前展示是否可信，但不会被连续弹窗打断。
5. 用户主动导出 JSON 备份，并可在另一环境手动导入。
6. 用户将鼠标悬停在股票上，查看日内价格、成交和基础估值信息，无需打开新页面。
7. 用户需要处理持久化配置时，可分别清空为一个空的默认分组，或恢复首次运行的示例数据。

## v0.1 MVP

- A 股、港股名称、拼音简称及代码搜索和展示；覆盖科创板，并支持北交所证券简称、新旧代码及 `920` 代码直查
- Activity Bar 入口与原生 Tree View
- 自选股的增删、跨组移动与组内排序
- 分组的增删、重命名和折叠
- 自动刷新、手动刷新、缓存、过期判断和请求合并
- 一个状态栏项目，轮播并可点击打开自选
- 原生悬浮行情卡，展示日内价格、成交、PE(TTM) 与总市值
- VS Code 本机持久化
- JSON 导入、导出、清空和恢复默认数据
- 可替换行情提供器接口
- 腾讯 A 股与港股行情提供器
- 涨跌颜色习惯配置

## 非目标

第一阶段明确不做：

- 基金、加密货币、外汇和期货
- 新闻、公告、舆情和 AI 分析
- 持仓成本、资产、盈亏和投资组合
- K 线、盘口和复杂图表
- 提醒、Webhook、自动交易和券商下单
- 付费功能、订阅、FishStock 账户和 FishStock 自有服务器
- 遥测或用户行为分析
- Marketplace 发布

## 体验原则

- 默认安静：后台刷新不弹成功通知，失败只改变当前状态。
- 一眼可懂：状态使用“休市”“数据过期”“暂不可用”等直接文字。
- 界面收敛：不使用 Webview；侧边栏最多两层；状态栏只有一个项目。
- 尊重主题：使用 VS Code ThemeColor，不设置醒目的状态栏背景色。
- 不假装实时：休市、延时或过期数据必须明确标识。

## 成功标准

v0.1 的成功不是行情覆盖面，而是原型闭环：

- 可以在 Extension Development Host 中稳定激活。
- 用户可完成自选、分组、排序、刷新和备份恢复。
- 数据源可以在不改动 UI 和存储模块的情况下替换。
- 编译、lint、核心单元测试和本地 VSIX 打包可重复通过。
