# FishStock 产品定义

## 产品定位

FishStock 是面向开发者的轻量 VS Code 自选行情工具。它只解决一个问题：编码过程中无需离开编辑器，就能安静地看一眼少量关注股票、指数或商品期货的价格和涨跌状态。

产品关键词是：低干扰、本地优先、透明、克制。

## 目标用户

- 日常在 VS Code 或兼容编辑器中工作，希望偶尔查看行情的开发者
- 只需要维护小型自选列表，不需要投资组合管理的人
- 重视隐私，不希望为了基础行情注册产品账户或上传自选数据的人

## 核心场景

1. 用户在 Activity Bar 打开 FishStock，通过同级 `Stock` 和 `Futures` 视图快速扫视自选。
2. 用户在状态栏看到一个自选条目的简短行情，几秒后自动轮播到下一个。
3. 用户按名称、简称或代码搜索个股或指数，确认匹配结果后直接加入目标分组；科创板、北交所和市场指数不因品种类型被遗漏，其他自选变更也只保存在本机。
4. 用户发现行情刷新失败、市场休市或数据已经过期时，能够理解当前展示是否可信，但不会被连续弹窗打断。
5. 用户将鼠标悬停在个股上，查看日内价格、成交、基础估值和上市板块，无需打开新页面。
6. 用户按品种名称或合约代码搜索国内商品期货，在同一次预览中选择主连或当前有效月份合约。
7. 用户首次打开时可从预置的股票、指数、银行和五个商品期货主连行情开始，并可分别清空或恢复股票、期货默认数据。

## 0.3.x MVP

- A 股、港股及市场指数的名称、拼音简称和代码搜索与展示；覆盖科创板，并支持北交所证券简称、新旧代码及 `920` 代码直查
- Activity Bar 入口与原生 Tree View
- 自选条目的增删、跨组移动与组内排序
- 分组的增删、重命名和折叠
- 自动刷新、手动刷新、缓存、过期判断和请求合并
- 一个状态栏项目，轮播并可点击打开自选
- 原生悬浮行情卡；个股展示日内价格、成交、PE(TTM)、总市值与上市板块，期货展示昨结、成交量、持仓量与交易所
- VS Code 本机持久化
- 股票和期货独立的本机自选数据，以及各自的清空和恢复默认能力
- 可替换行情提供器接口
- 腾讯 A 股与港股行情提供器
- A 股和港股市场指数行情
- 国内商品期货主连和有效月份合约行情
- 涨跌颜色习惯配置

## 非目标

第一阶段明确不做：

- 基金、加密货币和外汇
- 新闻、公告、舆情和 AI 分析
- 持仓成本、资产、盈亏和投资组合
- K 线、盘口和复杂图表
- 提醒、Webhook、自动交易和券商下单
- 付费功能、订阅、FishStock 账户和 FishStock 自有服务器
- 遥测或用户行为分析
- Marketplace 发布

## 体验原则

- 默认安静：后台刷新不弹成功通知，失败只改变当前状态。
- 一眼可懂：状态使用“休市”“数据过期”“暂不可用”等直接文字。
- 界面收敛：不使用 Webview；侧边栏最多两层；状态栏只有一个项目。
- 尊重主题：使用 VS Code ThemeColor，不设置醒目的状态栏背景色。
- 不假装实时：休市、延时或过期数据必须明确标识。

## 成功标准

0.3.x 的成功不是行情覆盖面，而是完成稳定、可检查的本地行情闭环：

- 可以在 Extension Development Host 中稳定激活。
- 用户可完成自选、分组、排序、刷新、清空和默认数据恢复。
- 数据源可以在不改动 UI 和存储模块的情况下替换。
- 编译、lint、核心单元测试和本地 VSIX 打包可重复通过。

## 0.4.x 可信与顺手

0.4 系列不做新品类，把"看一眼"这个动作做深：

- 交易日历：内置 A 股 2024–2026 年与港股 2025–2026 年交易所节假日，休市状态可信；非交易日停止自动轮询，更安静。
- 行情跳转：点击自选条目在浏览器打开东方财富或新浪期货详情页，深度信息交给外部页面，不违背轻量定位。
- 视图展示方式：每个视图独立的默认顺序、按涨跌幅排序和涨跌筛选，只影响展示，不改变自选底层顺序。

## 0.4 已定决策

- 数据源策略：继续使用腾讯、新浪公开网页端点，接受字段与访问策略的变更风险，不引入账户、授权或费用。
- 稳定性优先级：先做交易日历；备用行情源和完整期货交易规则（夜盘、各品种到期规则）留到后续版本。
- 品类边界：暂不增加基金或美股；若未来增加，仍坚持独立同级 View，并单独评估数据授权要求。
