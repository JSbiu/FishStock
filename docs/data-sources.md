# 行情源说明

> 审查基线：FishStock 0.6.1，2026-08-19。本文件记录当前实现、固定响应样本、交易所公开安排和本地联调观察，不代表数据供应商提供了正式 API 契约、使用授权或可用性承诺。

## 当前数据源

FishStock 的股票、指数和境内交易所 ETF 使用腾讯行情端点：

```text
https://qt.gtimg.cn/q=<symbols>&fmt=json
```

添加自选时使用腾讯搜索端点：

```text
https://smartbox.gtimg.cn/s3/?q=<名称、简称或代码>&t=all
```

北交所证券简称及新旧代码映射使用北京证券交易所公开页面：

```text
https://www.bse.cn/service/code_mapping.html
```

0.6.1 的实现不发送 Cookie、Referer 或登录凭据，本地联调可以批量获取 A 股、港股、市场指数和沪深 ETF。请求从 VS Code 扩展进程直接发往腾讯，不经过 FishStock 服务器。无需登录即可访问只描述当前技术现象，不等同于供应商对第三方客户端作出的授权或长期承诺。

## 返回解析

腾讯端点返回 GBK 编码的 JSON 对象，每个股票对应一个数组。当前只读取展示行情所需的最小字段：

| 索引 | 含义 |
| --- | --- |
| `[1]` | 股票名称 |
| `[3]` | 最新价 |
| `[4]` | 昨收价 |
| `[5]` | 今开价 |
| `[30]` | 行情更新时间 |
| `[33]` | 最高价 |
| `[34]` | 最低价 |
| `[36]` | 成交量；A 股为手，港股为股 |
| `[37]` | 成交额；A 股为万元，港股为港元 |
| `[38]` | A 股换手率 |
| `[39]` | 市盈率 PE(TTM) |
| `[45]` | 总市值，单位为亿元 |
| `[52]` | A 股静态市盈率，当前不展示 |
| `[59]` | 港股换手率 |

涨跌额和涨跌幅由 FishStock 根据最新价与昨收价统一计算，不直接依赖更多供应商字段。

提供器把成交额和总市值统一换算成对应币种的基础金额；A 股成交量保留“手”，港股成交量保留“股”。浮窗中的“市盈率 TTM”读取 `[39]`，不使用 A 股静态市盈率 `[52]`。扩展字段为空、为零占位或不可解析时显示 `—`，不会影响现价展示。

搜索端点返回证券代码、名称、拼音简称和品种类型。Stock 接受 `GP-A` 及其科创板等 A 股子类型、港股 `GP` 和指数 `ZS`；Fund 只接受上海、深圳市场的 `ETF` 类型。类型为 `KJ` 的场外基金和 ETF 联接基金，以及 LOF 等其他基金类型均被过滤。同名的跨交易所指数别名只在 Stock 中保留首个；同主题的多只 ETF 会保留供应商返回的不同产品，供用户按名称和代码选择。

2026-08-04 本地联调“电网设备ETF”返回 `159326.SZ`、`561380.SH`、`560390.SH` 和 `159320.SZ` 四只交易所 ETF，同时返回两只 `KJ` 类型的场外联接基金；固定回归样本验证 Fund 只接收前者。ETF 行情数组的现价、昨收、日内高低、成交量、成交额、换手率和时间字段与现有沪深行情格式兼容；不适用或为空的估值字段显示 `—`。

腾讯搜索端点目前不会返回北交所股票。FishStock 因此读取北交所官方新旧代码对照表，用于证券简称、旧代码和当前 `920` 代码匹配；VSIX 内置发布时获取的官方快照，成功更新结果在当前 VS Code Profile 的 `globalState` 中缓存 7 天。官方页面暂时不可用时优先使用最近缓存，否则使用内置快照。对于对照表尚未包含的新上市股票，输入完整代码后会直接请求腾讯行情，取得股票名称并生成添加预览。

## 国内期货解析与有效合约

新浪期货行情返回 GB18030 文本，每个合约对应一个逗号分隔数组。FishStock 当前读取：

| 索引 | 含义 |
| --- | --- |
| `[0]` | 合约名称 |
| `[1]` | 行情时间 |
| `[2]` | 今开价 |
| `[3]` | 最高价 |
| `[4]` | 最低价 |
| `[8]` | 最新价 |
| `[10]` | 昨日结算价 |
| `[13]` | 持仓量 |
| `[14]` | 成交量 |
| `[15]` | 交易所简称 |
| `[17]` | 行情日期 |

国内期货涨跌按最新价与昨结价计算，不使用通常为空的昨收字段。夜盘响应若以次一交易日标记日期，FishStock 会在返回时钟与本机中国标准时间接近时还原实际自然日，避免周五夜盘被误判为未来行情。主连代码以 `0` 结尾，只用于连续观察；月份合约才代表具体交割月份。搜索品种时，FishStock 会生成未来 24 个月的四位年份代码和郑商所三位年份代码候选，批量请求后只保留行情日期与该品种主连一致的合约，因此不会把端点仍能返回历史报价的到期合约列为当前有效合约。明确输入月份合约代码时也执行相同校验。

## 交易时段与期货兼容边界

所有时段都按中国标准时间计算。A 股采用 09:15–09:25 开盘集合竞价、09:30–11:30 与 13:00–14:57 连续交易、14:57–15:00 收盘集合竞价；港股采用 09:00–09:30 开市前时段、09:30–12:00 早市、13:00–16:00 午市和最晚至 16:10 的收市竞价，半日市最晚至 12:10。内置日历覆盖 A 股 2024–2026 年、港股 2025–2026 年，并登记港股半日市；覆盖期外回退为周一至周五判断。

## 请求策略

- 股票、指数和 ETF 每批最多 50 个代码，减少 URL 长度和单次响应规模。
- 国内期货同样每批最多 50 个代码；搜索只展开最相关品种的月份合约，其他匹配品种仅展示主连。
- 请求超时为 10 秒。
- 搜索输入采用 250 毫秒防抖，新输入会取消上一搜索请求。
- 北交所目录不在启动或后台刷新时请求；只有用户主动搜索且缓存超过 7 天时才尝试更新，更新失败后 24 小时内不重试。
- 搜索无结果且输入可识别为股票代码时，只追加一次单股行情查询。
- 相同自选集合的并发刷新会合并。
- 非强制刷新可复用 10 秒内缓存。
- 请求失败时保留最近一次成功行情：交易中在过期阈值内保留 `live` 并附最近刷新错误，持续失败超过阈值后标记“刷新超时”；休市时保留“休市”并附错误；没有缓存时显示“暂不可用”。
- 腾讯股票、腾讯 ETF 或新浪期货行情返回 HTTP 403 时，对应模块的后台自动刷新按 15 分钟、30 分钟、1 小时、2 小时、最长 6 小时递增退避，不在退避期内重复访问；用户主动刷新始终立即探测，成功后恢复正常周期。
- 常规自动刷新只请求当前处于交易时段的条目；同一 View 内的 A 股、港股和不同期货夜盘组互不连带。
- 开盘、休息和收盘边界立即刷新展示，并对发生切换的条目补一次强制请求；手动刷新始终请求当前 View 全部条目。
- 行情时间只用于判断是否属于当前或最近交易日以及是否异常超前；请求新鲜度由最近一次成功取得该条目的时间判断，价格和行情时间没有变化不会单独触发过期。

## 已知限制

腾讯和新浪端点都没有面向 FishStock 的正式接口契约，字段或访问策略未来可能变化。因此供应商格式分别隔离在 `TencentDataProvider` 和 `SinaFuturesProvider` 内，Tree View、状态栏和本地存储不直接依赖供应商字段。

北交所公开对照表主要解决全面启用 `920` 代码后的存量股票映射。没有旧代码的新上市股票可以按完整 `920` 代码添加；若其尚未进入官方对照表，暂时不能只凭中文名称或拼音检索。后续应优先寻找北交所正式、完整且适合客户端低频访问的证券信息文件，而不是引入来源不清晰的股票列表接口。

指数行情复用现有价格、涨跌、日内高低、成交和估值字段；供应商没有提供或不适用于指数的字段显示 `—`。当前只支持腾讯搜索可返回且行情端点可取价的 A 股与港股指数，不提供指数成分股、权重、点位贡献或历史走势。

ETF 首版只支持腾讯搜索明确标记为 `ETF` 且交易所为上海或深圳的产品。代码格式与 A 股相同，但存储和 View 独立；当前不展示净值、溢折价、份额、规模、跟踪误差、申购赎回状态或成分股，也不支持场外基金、ETF 联接基金、LOF 和港股 ETF。

新浪搜索只负责发现国内期货品种，具体月份合约由候选查询确认。新增品种还必须进入 FishStock 的交易时段规则表；当前不支持期权、外盘期货，也不保证无成交的远月合约会出现在有效合约预览中。主连是数据供应商构造的连续观察序列，不应被理解为可交易合约。

当前不会为同一品类并联多个备用源。只有现有源出现实际覆盖或稳定性问题时，再基于失败证据增加备用提供器。

## 候选方案比较

| 方案 | 覆盖 | 稳定性判断 | 使用限制 | 0.6.1 结论 |
| --- | --- | --- | --- | --- |
| 腾讯公开网页端点 | A 股、港股、部分市场指数、沪深 ETF | 当前样本和低频批量请求可用；无 FishStock 可依赖的正式契约 | 字段和访问策略可能变化；可访问不等于获得再分发授权 | 继续作为股票、指数与 ETF 当前实现，保持适配器隔离 |
| 新浪公开网页端点 | 国内期货主连与月份合约 | 当前样本可用；无 FishStock 可依赖的正式契约 | 需要普通财经页 `Referer`；交易所、交易时段和合约规则需自行补足 | 继续作为国内商品期货当前实现，限制在低频查看 |
| 交易所公开页面、证券目录和交易日历 | 静态证券信息、交易安排；通常不提供统一免费实时行情 | 官方参考信息更适合校验和补充元数据 | 市场分散、格式不同，不能直接替换跨市场实时行情源 | 已用于北交所代码映射、节假日和期货品种时段规则，继续滚动维护 |
| 具有正式文档与授权的商业行情服务 | 取决于供应商，通常可覆盖更多市场 | 契约、限频和支持通常更清晰 | 可能要求账户、密钥、付费和展示/再分发许可 | 当前条件不引入；若真实失败率或规模上升，再评估迁移成本与授权 |
| 其他财经网站的未公开网页端点 | 覆盖可能较广 | 与当前公开端点存在相同或更高的不确定性 | 来源、字段和使用条件可能更难确认 | 不仅为了增加备用源或“能跑”而接入 |

0.6.1 继续保持腾讯与新浪两个适配器，不把供应商字段或开休市推断泄漏到业务层；客户端分别记录行情源时间和成功获取时间，以真实请求失败而非价格是否变化判断连接新鲜度。在 README、隐私和支持说明中公开访问边界，不承诺跨地区稳定性。将真实错误率、字段变化、访问拒绝和覆盖缺口作为是否更换或增加行情源的依据；若未来形成收入或扩大用户规模，重新评估正式授权行情服务。
