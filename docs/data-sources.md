# 行情源说明

## 当前数据源

FishStock 当前默认使用腾讯行情端点：

```text
https://qt.gtimg.cn/q=<symbols>&fmt=json
```

添加自选时使用腾讯搜索端点：

```text
https://smartbox.gtimg.cn/s3/?q=<名称、简称或代码>&t=all
```

北交所证券简称及新旧代码映射使用北京证券交易所公开页面：

```text
https://www.bse.cn/service/code_mapping.html
```

实测 A 股和港股均可直接批量请求，不需要 Cookie、Referer 或登录态。请求从 VS Code 扩展进程直接发往腾讯，不经过 FishStock 服务器。

当前优先覆盖：

| 市场 | FishStock 代码 | 腾讯代码 |
| --- | --- | --- |
| 上海 A 股 | `600519.SH` | `sh600519` |
| 深圳 A 股 | `000001.SZ` | `sz000001` |
| 北京 A 股 | `920189.BJ` | `bj920189` |
| 港股 | `00700.HK` | `r_hk00700` |

## 返回解析

腾讯端点返回 GBK 编码的 JSON 对象，每个股票对应一个数组。当前只读取展示行情所需的最小字段：

| 索引 | 含义 |
| --- | --- |
| `[1]` | 股票名称 |
| `[3]` | 最新价 |
| `[4]` | 昨收价 |
| `[5]` | 今开价 |
| `[30]` | 行情更新时间 |
| `[33]` | 最高价 |
| `[34]` | 最低价 |
| `[36]` | 成交量；A 股为手，港股为股 |
| `[37]` | 成交额；A 股为万元，港股为港元 |
| `[38]` | A 股换手率 |
| `[39]` | 市盈率 PE(TTM) |
| `[45]` | 总市值，单位为亿元 |
| `[52]` | A 股静态市盈率，当前不展示 |
| `[59]` | 港股换手率 |

涨跌额和涨跌幅由 FishStock 根据最新价与昨收价统一计算，不直接依赖更多供应商字段。

提供器把成交额和总市值统一换算成对应币种的基础金额；A 股成交量保留“手”，港股成交量保留“股”。浮窗中的“市盈率 TTM”读取 `[39]`，不使用 A 股静态市盈率 `[52]`。扩展字段为空、为零占位或不可解析时显示 `—`，不会影响现价展示。

搜索端点返回股票代码、名称、拼音简称和品种类型。FishStock 接受 `GP-A` 及其科创板等 A 股子类型，只保留上海、深圳、北京 A 股和港股股票，过滤基金、指数及其他品种，再转换为统一代码后展示给用户确认。

腾讯搜索端点目前不会返回北交所股票。FishStock 因此读取北交所官方新旧代码对照表，用于证券简称、旧代码和当前 `920` 代码匹配；VSIX 内置发布时获取的官方快照，成功更新结果在当前 VS Code Profile 的 `globalState` 中缓存 7 天。官方页面暂时不可用时优先使用最近缓存，否则使用内置快照。对于对照表尚未包含的新上市股票，输入完整代码后会直接请求腾讯行情，取得股票名称并生成添加预览。

## 请求策略

- 每批最多 50 只股票，减少 URL 长度和单次响应规模。
- 请求超时为 10 秒。
- 搜索输入采用 250 毫秒防抖，新输入会取消上一搜索请求。
- 北交所目录不在启动或后台刷新时请求；只有用户主动搜索且缓存超过 7 天时才尝试更新，更新失败后 24 小时内不重试。
- 搜索无结果且输入可识别为股票代码时，只追加一次单股行情查询。
- 相同自选集合的并发刷新会合并。
- 非强制刷新可复用 10 秒内缓存。
- 请求失败时保留最近一次成功行情并标记为“数据过期”；没有缓存时显示“暂不可用”。
- 行情时间与当前交易时段结合判断开市、午休、收盘和跨日旧数据。

## 已知限制

腾讯端点没有面向 FishStock 的正式接口契约，字段或访问策略未来可能变化。因此供应商格式被隔离在 `TencentDataProvider` 内，Tree View、状态栏和本地存储不直接依赖腾讯字段。

北交所公开对照表主要解决全面启用 `920` 代码后的存量股票映射。没有旧代码的新上市股票可以按完整 `920` 代码添加；若其尚未进入官方对照表，暂时不能只凭中文名称或拼音检索。后续应优先寻找北交所正式、完整且适合客户端低频访问的证券信息文件，而不是引入来源不清晰的股票列表接口。

当前不为“更完整”而同时接入多个接口。只有腾讯源出现实际覆盖或稳定性问题时，再基于失败证据增加备用提供器。
