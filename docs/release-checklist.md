# FishStock 发布验收清单

用户和开发者可以随时提出感受、问题和想法，但不承担固定版本流程。每个版本由维护者独立完成以下门槛。

## 自动门槛

运行：

```powershell
pnpm run release:check
```

该命令生成稳定通道包；预发布通道使用 `pnpm run release:check:pre-release`。

命令必须依次通过：

- ESLint 与严格 TypeScript 编译。
- 全部单元和回归测试。
- 独立用户目录中的 VS Code Extension Host 冒烟测试。
- 扩展激活、Stock/Fund/Futures/Holdings 打开、关键命令注册和全部展开命令执行。
- `package.json`、README 与 CHANGELOG 版本一致性。
- Publisher、MIT 许可证、Preview、免费定价、发布通道和 Marketplace PNG 图标一致性。
- 隐私与支持说明存在，并明确无遥测、第三方网络请求、诊断和反馈入口。
- VSIX 文件清单检查，不包含源码、测试、脚本、本地记忆或协作说明。
- 生成非空且发布通道属性与验收命令一致的当前版本 VSIX。

任何一项失败都不得提交为完成版本。

## 维护者验收

- 从上一版本升级后，自选数据、分组折叠状态和视图模式保持不变。
- Stock、Fund、Futures 与 Holdings 的主要功能均有入口，命令名称和图标可理解。
- 从 0.6.x 升级后，股票、基金、期货自选及其分组、折叠和展示状态保持不变；Holdings 首次为空，不创建虚构持仓。
- Holdings 只允许 A 股、港股和境内交易所 ETF；数量必须是正整数，平均成本必须是正数，重复或无效标的不写入本地状态。
- Holdings 管理器在编辑器区域单例打开；可连续搜索、多选添加，在同一表格修改多行，并勾选多条从草稿删除。
- 添加、编辑和批量删除在点击“保存全部”后一次生效；任一无效行或存储失败时不产生部分保存，内存快照保持原值。
- 从 Tree View 执行添加会聚焦管理器搜索框，执行编辑会聚焦对应行；保存后 Tree View、状态栏和自动刷新范围同步更新。
- 管理器关闭且草稿未保存时提供保存、继续编辑和放弃；放弃更改可以恢复当前持久化状态。
- 管理器遵循当前涨跌颜色配置，复用 `live`、`closed`、`stale`、`error`，不加载外部资源或直接发起网络请求。
- 持仓市值、成本市值、浮动盈亏和收益率计算正确；人民币和港币独立分组与汇总，不进行汇率换算。
- `closed` 和 `stale` 的有效行情继续计算持仓结果并明确标注；`error` 或无有效价格时不展示估算盈亏。
- 当日盈亏在盘中、午休与收盘后照常显示；盘前、周末与节假日显示 `—`。
- 刷新失败或超时但行情仍属于当天时，当日盈亏继续显示最后一次数值，不出现金额与占位符之间的跳变；缓存跨了交易日时退回 `—`，不把上一交易日的涨跌标成今日盈亏。
- Holdings 排序提供五个维度（默认顺序、浮动盈亏收益率 / 金额、今日盈亏收益率 / 金额），再次选择同一项可切换升 / 降序；排序维度在重载后保持，旧数据缺少该字段时回退为默认顺序。
- 设置 `fishStock.holdings.hkdToCnyRate`（如 `0.8557`）后，港币持仓的市值、浮动盈亏、当日盈亏在 Tree View、悬浮卡、编辑器管理器三处都按人民币展示，且**百分比与折算前完全一致**；留空配置则恢复原币种显示。编辑器管理器的港币合计行应显示「合计 港币折 CNY」。
- 悬浮卡与 README 必须包含数据来源与差异声明（第三方公开行情源、与券商对账可能有差异、以券商为准）。
- 默认顺序下持仓条目右键菜单可上移 / 下移，顺序在重载后保持；手动排序只在同币种分组内生效，跨币种不参与；非默认排序时上移 / 下移菜单项应隐藏，从命令面板执行应给出提示而非静默失败。
- 停牌持仓（行情源标记停牌）不得被算成「今日 ±0」：描述行给出「停牌」、图标为暂停样式、悬浮卡当日盈亏显示 —。可用处于停牌期的标的（如 2026-09-15 的东兴证券）核对，复牌后应自动恢复正常显示。
- 收盘价取回：15:00 收盘后 60 秒内仍应按调度间隔刷新，使最终收盘价落定；核对收盘后的当日盈亏是否跟随最终收盘价，而不是停在 14:59:5x。可直接断言 `shouldAutoRefreshSymbol` 在收盘后 30 秒为真、90 秒为假；午休（11:30）与开盘间歇（09:25）开始后 20 秒内同样应为真。
- 股票与 ETF 自选为已在持仓的条目在图标上挂「持」角标，且**不改变名称、股价、涨跌幅的文字颜色**；同一代码在股票自选与 ETF 自选之间不互相误标，期货自选没有该角标。
- 涨跌幅文字不做单独配色（`TreeItem.description` 只接受纯字符串，无法给其中一段上色），涨跌方向由条目左侧带颜色的箭头图标表达，验证时确认箭头颜色与涨跌幅正负一致并遵循当前涨跌颜色配置。
- Holdings Tree View 描述行的字段在 `Settings → fishStock.holdings.treeViewFields` 中可勾选，默认四个字段（数量、市值、浮动盈亏、当日盈亏）全开；关掉任意字段后描述行立即精简，未勾选的字段在悬浮面板与编辑器管理器仍可见；至少保留一项；勾选变化后 Tree View 立即刷新。从标题栏 `2_view@2` 分组的命令可打开 QuickPick 多选面板。
- 编辑器管理器合计行按币种汇总市值、浮动盈亏、收益率与当日盈亏；未填全或没有行情的条目不计入并标注待填写数量，修改数量或成本后合计同步更新。
- 持仓浮窗和管理器明确说明未包含费用、税费、分红和汇率；期货持仓、交易流水、已实现收益、多账户和资产曲线没有入口。
- 状态栏轮播分组可多选、全部取消并在重载后保持；未配置的现有用户默认包含全部分组。展示模式默认保持行情轮播，可切换并持久保存持仓盈亏轮播，始终只有一个状态栏项目。
- 打开 VS Code 时 FishStock 不切换活动侧边栏；全新工作区首次进入时四个 View 与三个自选品类的默认分组均展开，已有工作区保留用户布局，展开任一 View 不联动其余 View；手动刷新、断网和休市状态没有阻塞错误。
- A 股在 09:25–09:30、午休和收盘后停止常规自动刷新；港股午休独立于 A 股，半日市在收市竞价结束后休市。
- 国内商品期货分别验证 23:00、次日 01:00、次日 02:30 和仅日盘四类；周五夜盘归入下周一，节假日前一交易日晚不误判开盘。
- 同一 View 混合市场或不同期货夜盘组时，只刷新当前交易中的条目；开盘、休息、收盘边界及时更新展示。
- 手动刷新在午休、收盘、节假日和自动退避期间仍可立即请求，并以短暂状态栏消息区分刷新成功、当前休市、时段未收录和失败。
- `live`、`closed`、`stale`、`error` 的 Tree View、状态栏和浮窗含义一致；休市时的最近有效行情不会因刷新失败错误变成“实时”或“暂不可用”。
- 交易中连续成功获取但价格或行情时间未变化时保持 `live`；一次刷新失败或单个标的临时缺失在阈值内只显示警告，持续超过阈值后显示“刷新超时”。
- 上午行情在同一交易日的午休、下午和收盘后仍有效；期货夜盘行情可跨自然日进入所属交易日的日盘，前一交易日行情与异常超前时间分别显示明确原因。
- 脱敏诊断包含过期原因和持仓状态计数，但不包含自选名称、证券代码、持仓数量、平均成本、市值、盈亏、文件路径或工作区信息。
- 升级后未知期货品种不被删除；新搜索结果只允许添加交易时段已收录的商品品种。
- 清空、恢复默认和删除等破坏性操作仍有明确确认。
- README、CHANGELOG 与可见行为一致。
- Marketplace 名称、简介、关键词、图标、许可证、隐私和支持链接可正常显示。
- 公开说明腾讯/新浪行情端点的访问限制，HTTP 403 不形成高频重试。
- 从 VSIX 安装、升级、禁用、重新启用和卸载不会阻塞 VS Code；升级保留本地自选。
- `git status --short` 不包含遗漏文件；VSIX、`out/` 和本地记忆不进入提交。

## 版本规则

- 规划中的功能里程碑滚动次版本号。
- 交互优化、性能优化、缺陷修复、测试与文档修正只滚动修订版本号。
- 不因零散用户反馈等待发版；反馈进入待办，按风险和价值安排后续版本。
